# Security Policy

## Deception Safety & Operational Ethics

**LANTERNFISH** is designed exclusively for defense, simulated cyber deception, canary monitoring, and intrusion tracing. 

- **Simulated Telemetry:** The platform does not scan external infrastructure, execute live exploits, or deploy malware.
- **Canary Tokens:** All honeytokens, credentials, and files generated by this system are synthetic digital markers with zero operational authorization in production environments.

---

## Reporting Vulnerabilities

If you discover a security vulnerability within the LANTERNFISH codebase:

1. **Do not create a public GitHub issue.**
2. Send an email to the repository maintainer with:
   - Detailed description of the vulnerability.
   - Steps to reproduce.
   - Potential impact assessment.
3. We will acknowledge receipt within 48 hours and work on an immediate fix.
